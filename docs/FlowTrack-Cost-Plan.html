Key takeaways

  • Running the software is cheap: ~$175/month at launch, ~$320/month at 4,000 users.
  • Only ~355 paying users are needed to become profitable in Phase 1.
  • At full capacity, a single Phase 1 server earns ~$57,900/year; Phase 2 earns ~$164,160/year.
  • Infrastructure is always a tiny fraction of revenue — marketing is the main growth lever.
  • Costs drop a further 30–50% with AWS Reserved Instances / Savings Plans.

Assumptions

  • Blended net revenue of $4.00 per paid user / month (mix of Starter $2.49, Professional $3.99, Enterprise $5.99).
  • Variable cost per user ~$0.70 (Stripe + storage) → gross margin $3.30/user.
  • AWS on-demand prices (us-east-1), rounded; actual bills vary with usage.
  • Screenshots stored in S3; database on managed RDS.
